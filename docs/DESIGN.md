# 전 세계 기업별 HS 무역 관측 원장

범위는 한국 기업이 아니라 전 세계 법인·거래상대방이다. 어떤 기업의 소재국이 미확인되어도 관측 원장은 수용한다. 국가 전체 통계, 기업의 신고·선적 관측, 품목 거래 여부는 서로 다른 데이터다.

이번 배포는 Python 3.11 이상과 표준 라이브러리로 실행하는 로컬 단일 사용자 수집·검증·집계 프로그램이다. 기존 저장소 지정이 없으므로 외부 조직·운영 DB를 변경하지 않는다. 글로벌 전수 데이터베이스나 유료 데이터 사용권을 확보했다는 의미가 아니다.

## 데이터 계약

- 원장 단위: 원천 × 원천 레코드 × 버전. 금액은 Decimal로 검증하고 문자열로 보존한다.
- 기업 식별: 제공된 등록번호 또는 원천 내 기업 식별자. 이름만 같은 기업은 병합하지 않는다. 영문명이 같거나 등록 국가가 다르면 별개다. 원천 식별자는 법인등록번호가 아니다.
- 기업의 소재국, 세관 신고국, 원산지, 출발국, 도착국은 독립 필드다. 공급자를 수출자로, 수하인을 수입자로 자동 변경하지 않는다.
- HS 원문·개정판·분류 근거를 보존한다. 6단위는 형식 정규화이며 관세 품목분류의 법적 확인은 아니다. 개정판을 모르면 UNKNOWN이며 연도만으로 채우지 않는다.
- 결측 금액은 null. 거래 여부 행은 선적 건수가 아니다. FOB/CIF, 통화, 개정판, 원천, 날짜 기준이 다른 값은 같은 합계에 넣지 않는다.
- 같은 원천·키·버전 재수집은 멱등. 같은 버전에 다른 내용은 거부한다. 최신 취소는 과거 버전 재노출을 막는다.
- 출처 간 같은 거래는 검증된 신고번호·품목행 키가 있을 때만 후보로 연결한다. 자동 글로벌 합산은 하지 않으며 출처별 통계와 중복·충돌 보고를 제공한다.
- 실제 자료와 가상 테스트 자료는 원천 등록과 모든 집계에서 분리한다.
- 공급사 사용권은 로컬 정책으로 표현한다. 정책 입력이 실제 계약의 적법성을 증명하지 않는다. 원문 반출은 명시적 허용이 있어야 한다.

## 구현 경계

identity는 기업 식별, trade는 검증·집계·출처 간 대조, sources는 HMRC/UN Comtrade 및 파일 변환, coverage는 경제권·원천 가용성, storage는 로컬 저장만 담당한다. API 호출과 파싱은 DB 쓰기 트랜잭션 밖에서 수행한다. .env, 임의 코드 실행, 유료 자동 결제, 외부 배포는 없다.

## 연결

HMRC의 /Trade는 기업·품목·월의 존재 관측으로 처리한다. UN Comtrade preview는 국가 통계이며 샘플/제한 응답으로 처리한다. CSV/JSONL 계약은 어떤 국가의 적법하게 확보한 거래자료도 받을 수 있다. 상용 공급사의 비공개 API 스키마를 추측한 어댑터는 만들지 않는다.

## 검증 기준

금액 정밀도·결측·단위·HS 선행 0·국가 역할·버전·취소·권한·출처 중복·가상자료 분리·페이지 제한·스키마 변경·외부 URL 차단을 회귀시험한다. 인터넷 연결 실패를 0건으로 성공 처리하지 않는다. 실제 API 대량 수집은 현재 실행환경의 DNS 제한 때문에 별도 검증 항목으로 남긴다.
