# 확인된 경계

검증 기준일은 2026-09-12입니다.

1. 전 세계 모든 회사의 실적을 확보한 데이터베이스가 아닙니다. 이 공개 저장소에는 실제 기업 거래나 국가 총액 표본을 재배포하지 않습니다. 예제 생성기의 관측 24건은 가상 자료이며 소프트웨어 시험용입니다.
2. 유료 원천자료·API 키·기업 동의 신고자료를 새로 취득하지 않았습니다. 특정 상용 공급사와의 실제 계약·수집 성공을 주장하지 않습니다.
3. HMRC/Comtrade의 공식 계약에 맞춘 요청과 파서는 구현했지만 런타임 외부 DNS가 실패했습니다. 모의 응답 시험과 실시간 네트워크 성공은 별개입니다. 원천 서비스의 장애라고 결론내릴 근거는 없습니다.
4. 국가 코드 지원 목록은 실제 데이터 연결 목록이 아닙니다. EU 같은 집합 경제권, 과거 국가 코드, 특수 세관 지역은 추가 명시적 매핑이 필요합니다. 영국 API의 회사 등록은 법적 소재국을 확인한 근거로 자동 사용하지 않습니다.
5. HS 검증은 형식과 개정판 라벨을 검증합니다. 모든 세번의 유효성·상세 품목분류·판례·관세율을 검증하지 않습니다. 개정판 간 일대다 변환은 구현하지 않았습니다.
6. 업체 ID는 원천 내 식별 또는 사용자가 제공한 등록번호에 근거합니다. 법인등록부 실시간 확인·회사 그룹 전체 연결·확률적 법인 매칭은 없습니다.
7. 출처 내부의 안정적인 키/버전 중복과 확인된 문서 키의 출처 간 충돌을 처리합니다. 키가 없거나 두 자료의 식별 방식이 다르면 글로벌 중복 제거를 자동으로 완성하지 않습니다.
8. FOB/CIF·통화·개정판·역할·기간 기준이 다른 값은 분리합니다. 환율 환산·FOB/CIF 환산·단가 추정·미관측 거래 추정 모델은 구현하지 않았습니다.
9. 파일은 최대 128 MiB, 조회는 필터된 관측을 메모리에 적재합니다. 여러 국가 전체의 수십억 행을 처리하는 성능을 검증하지 않았습니다. 로컬 API는 출력 그룹을 1,000개로 제한하지만 그 전에 집계를 수행하므로 대용량 보호의 완전한 대안은 아닙니다.
10. 소스 정책은 로컬 이용 통제입니다. DB 파일 소유자에 대한 강제 보안 경계나 법률 검토를 대체하지 않습니다. 기업별 조회 결과를 제3자에게 전달하기 전 해당 계약을 확인해야 합니다.
11. 관측 버전은 보존하지만 국가 기준선은 같은 키의 최신 입력으로 갱신합니다. 0.2.0은 캡처 파일과 회사 관측 버전의 연결을 보존합니다. 해시는 canonical JSON의 무결성 확인이며 전자서명이나 원본 HTTP 바이트의 진위 인증이 아닙니다. 국가 기준선의 완전한 버전 계보와 원본 HTTP 자동 장기 보관은 없습니다.
12. 로컬 API는 외부 바인딩과 쓰기 메서드를 제공하지 않습니다. 운영용 IAM, 다중 테넌트, 인증·감사 무결성·장애 복구 SLA·클러스터 배포는 없습니다. 외부 저장소/운영 서버를 수정하거나 서비스를 배포하지 않았습니다.

13. offset 기반 재개는 조회 중 원천이 바뀌면 누락 가능성이 있습니다. 정렬 반복·범위 밖 응답은 검출하지만 모든 삽입·삭제를 검출하는 원천 스냅샷 토큰은 없습니다. 완료된 체크포인트를 재개해도 자동 갱신되지 않으므로 새 확인은 resume 없이 실행합니다.
14. 원본 실행본의 공개 사실 표본은 공개 저장소 이관에서 제외했습니다. 이관은 bulk 추출권이나 제3자 재배포권 취득을 뜻하지 않습니다. 실제 자료를 연결할 때 원천의 값 충돌과 생략을 캡처 annotations에 남겨야 합니다.
